## 光线的重要性

摄影的本质是记录光线。理解光线是拍出好照片的第一步。

### 自然光

- **黄金时刻**：日出后和日落前的一小时，光线柔和温暖
- **蓝调时刻**：日出前和日落后，天空呈现深蓝色
- **正午光线**：强烈直射，容易产生硬阴影

### 人造光

- 闪光灯
- 持续光源
- 反光板

## 构图法则

### 三分法

将画面分成九宫格，将主体放在交点或线上。

```
┌────┬────┬────┐
│    │ ★  │    │
├────┼────┼────┤
│    │    │    │
├────┼────┼────┤
│    │    │    │
└────┴────┴────┘
```

### 引导线

利用道路、河流等线条引导观众视线。

### 对称与平衡

创造视觉上的和谐感。

## 实用技巧

1. **观察光线**：拍摄前先观察光线的方向和强度
2. **简化画面**：去除干扰元素，突出主体
3. **尝试不同角度**：蹲下、爬高、侧面拍摄
4. **等待时机**：好的照片往往需要耐心等待

## 结语

摄影是一门艺术，也是一门技术。多拍、多看、多思考，你的摄影水平一定会不断提高。
